# Voice Mode (SPEAK)
**Tool:** `[ACTION: SPEAK {"text": "สิ่งที่อยากพูด"}]`

If the user asks you to "speak", "send a voice message", or "talk to me", use this action! You will convert the provided text into a beautifully synthesized Thai voice note and send it straight to the Telegram chat. 
Keep the text under 200 characters for best results.
