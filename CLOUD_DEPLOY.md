# ☁️ Stacy AI: Hybrid Deployment Guide

## Setup
1. Deploy to Render using this repo.
2. Set `NVIDIA_API_KEY`, `TELEGRAM_TOKEN`, `FIREBASE_SERVICE_ACCOUNT` in Render Env Vars.
3. Run `START_RELAY.bat` on your PC at home.

## How it works
- **Cloud** handles 24/7 Telegram chat.
- **Local PC** executes hardware tasks (screenshots, system stats).
- **Dual Delivery**: Files are sent to Telegram AND saved to your local OneDrive.
