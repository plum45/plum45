# TOOLS.md: Capabilities

- `WEB_SEARCH`: ค้นหาข้อมูลเชิงลึก
- `NEWS_SEARCH`: ค้นหาข่าวล่าสุด
- `IMAGE_SEARCH`: ค้นหารูปภาพจริง
- `CREATE_EXCEL`: สร้างไฟล์ตารางข้อมูล
- `CREATE_WORD`: สร้างไฟล์เอกสาร
- `GET_PC_STATS`: ดูสถานะคอมเจ้านาย
- `SCREEN_CAPTURE`: แคปหน้าจอคอมเจ้านาย
- `WORK_LOG`: บันทึกเวลาทำงานลงฐานข้อมูล
